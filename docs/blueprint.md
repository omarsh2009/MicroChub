# **App Name**: MicroChub

## Core Features:

- Product Catalog & Detail Pages: Users can browse electronics and tools across various categories (e.g., Mochi, ESP Devices, Arduino), view technical specifications, multiple images, and use cases, with options to add to wishlist.
- Configurable Product Options: Provides interactive selectors for users to customize hardware, features, or enclosures for specific products (e.g., DIY kits) before adding to cart.
- Secure User Accounts & Wishlists: User authentication (registration/login) for accessing personalized wishlists and managing their orders and preferences.
- Shopping Cart & Manual Payment Checkout: Core eCommerce flow allowing users to add/remove products, then proceed to checkout where they upload a screenshot of their Instapay/Telda payment proof for manual verification (supporting full payment or deposit).
- Order Status Dashboard: Users can track the progress of their purchases through statuses like Pending (waiting payment proof), Confirmed, Processing, and Ready/Completed, via a personalized dashboard.
- Custom Hardware Services Request System: A dedicated interface for requesting custom services (PCB design, schematic design, product customization, enclosure design), featuring project description input, file uploads, and budget/deadline fields.
- AI-Powered Project Summary Tool for Admins: An internal generative AI tool for administrators that analyzes and summarizes user-submitted custom service project descriptions, identifying key requirements and components to assist in generating quotes.
- Admin Dashboard for Operations & Product Management: Admin interface for verifying payments, updating order statuses, reviewing custom service requests, adding/editing/removing products, and managing uploaded files.

## Style Guidelines:

- Dark mode primary color: A vibrant purple-blue (`#7A33CC`) reflecting a futuristic tech vibe for interactive elements and highlights, providing strong contrast on a dark background.
- Background color: A very dark, desaturated variant of the primary hue (`#18151B`) to create a deep, immersive dark theme that reduces eye strain.
- Accent color: An electric blue (`#8CA8FF`) used for calls-to-action, active states, and subtle glowing effects to enhance the hacking/maker culture aesthetic.
- Headline font: 'Space Grotesk' (sans-serif) for its computerized and scientific feel, aligning with the technical brand identity.
- Body font: 'Inter' (sans-serif) for its modern, machined, and neutral aesthetic, ensuring readability for product descriptions and user content.
- Code snippets font: 'Source Code Pro' (monospace) for clear display of any code or technical text, emphasizing the engineering focus.
- Use sharp, vector-based icons with subtle glowing or metallic effects. Incorporate visual elements reminiscent of PCB traces, schematics, and terminal interfaces to reinforce the hacking/engineering theme.
- Adopt a clean yet technical, modular grid-based layout with ample dark spacing. Components should have well-defined borders or shadows to create a sense of depth and structure, inspired by Hackster-style interfaces.
- Implement subtle animations such as hover effects that involve a glow or shift in accent color, smooth transitions for dynamic content loading, and deliberate movements for interactive elements, contributing to a polished, futuristic user experience.
